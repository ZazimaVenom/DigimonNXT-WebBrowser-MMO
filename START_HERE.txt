EXTERNAL CLIENT DOWNLOAD URL - v0.7.2
The homepage now links directly to an external download host. Your game server
does not fetch, proxy or serve the client ZIP. Website/game traffic is unchanged.
Set windows['url'] in public_html\config\client_downloads.php to a permanent
public HTTPS download link. No real URL is supplied in this package; the download
stays unavailable until you set it. Upload the client ZIP once to your chosen
external host, not into the game website's downloads folder.
For an existing game, copy the External_Client_URL_Update ZIP's public_html
contents into your game folder. Delete the previous local client ZIP from
downloads. An included Apache .htaccess rule also blocks that old directory.
No database setup is needed for this homepage change. The full source includes
this correction; no companion client download package is needed on the server.
See docs\CLIENT_DOWNLOADS.md.

AUTOMATIC XAMPP PASSWORD SETUP - v0.7.2
1. Start Apache and MySQL in XAMPP.
2. Copy this package's public_html CONTENTS into your installed game folder.
   Keep your existing config\app.php when upgrading; it is updated automatically.
3. On the server PC open http://localhost/DigimonNXT/_setup.php.
4. Click CREATE / REPAIR SCHEMA. It changes the actual local MySQL root password
   to "QuestionMark123456?", saves that password in the installed game config,
   and then installs/upgrades/repairs the game while preserving saved accounts.
   FRESH REBUILD performs the same password step before deleting and recreating
   the configured game database. Use it only when you want to erase game saves.
5. Restart the tamer task and reopen the world console to load the new connection.

A blank XAMPP root password and the currently configured password are handled
automatically. If MySQL has another password not saved in the game config,
open "MySQL already has a different password" and enter that current password
once. It is masked and is not saved, echoed or sent in a URL.
There is NO separate password updater to run and NO manual config edit.

UPGRADE AN EXISTING GAME — KEEP YOUR SAVES
1. Back up the installed game files and digimon_nxt database.
2. Keep this extracted source folder outside the public web directory.
   Copy public_html contents over C:\xampp\htdocs\DigimonNXT.
   PRESERVE your installed config\app.php: database name, host, port and path.
   Copy the new config\version.php and every other updated application file.
3. Start Apache and MySQL in XAMPP. On the server PC, open:
   http://localhost/DigimonNXT/_setup.php
4. Choose CREATE / REPAIR SCHEMA. Schema 8 remains current; the repair preserves
   players, collections, parties, progression and existing AI rival accounts.
   DO NOT choose Fresh Rebuild for saved accounts: it deletes the game database.
5. Restart the existing tamer background task to load the updated PHP code:
   tools\stop_tamer_service_windows.bat
   tools\start_tamer_service_windows.bat
6. Open Dawn World. Old Cyberspace bookmarks route to safe Dawn destinations;
   saved positions are checked when players revisit maps. No save reset is needed.

EXPLORE ALL 264 DAWN MAPS
- Open Dawn World. Search by name or area number; filter environment and
  Wild Digimon / Rest areas. The atlas shows 24 destinations per page.
- Choose a destination card to travel. The map keeps the uploaded image's
  natural size; the camera scrolls with your tamer.
- Use WASD, arrows, numpad or the movement pad. Walls and edges block movement.
- Choose Area landings to reach separate paths and platforms in the same map.
- Follow marked gates or use Travel connections to visit neighbouring areas.
- Select a visible Digimon, or press E for the nearest signal. Approach along
  clear ground until it is in range, then choose Battle.
- Three active partners fight, with up to three party reserves. Scan arrives
  when a valid encounter begins. Materialize partners at 100% scan or more.
- Victory, defeat and disconnect restore your entire party to full HP and SP.
- Area 001 is a rest area; the other 263 areas support wild encounters.
- Click Enable sound once to allow Dawn music and sound in your browser.

KEEP TAMERS ACTIVE WITH NO PLAYERS — WINDOWS / XAMPP
1. Keep the server computer awake and MySQL running.
2. For a fresh installation, run tools\install_tamer_service_windows.bat once.
   Its default installed game folder is C:\xampp\htdocs\DigimonNXT.
   For another folder, set NXT_GAME_DIR and NXT_PHP in the launcher first.
3. Accept administrator elevation. The installer registers and starts the
   background startup task using the installed game's database settings.
4. Browsers and the world console can close. The task runs with no Windows
   user signed in and resumes after Windows starts. If MySQL stops, it retries.
5. tools\tamer_service_status_windows.bat checks the task. Tamer Activity
   shows the worker's connection status while its heartbeat is live.

Bots share one fair schedule. They take turns; all 1,000 do not act at once.
Browser tabs provide bounded fallback activity without multiplying bot speed.
Stopping/removing this game's task leaves the database and other MMOs intact.
See tools\README_TAMER_SERVICE.txt for custom paths and task management.

WORLD CONSOLE — PHYSICAL SERVER PC ONLY
Run tools\start_world_server_windows.bat and accept administrator elevation.
Requires Windows PowerShell 5.1 and XAMPP PHP 8.1+ with mysqli/mysqlnd.
Type help, then status. The same window shows live activity while you type.
All 52 existing administrator commands remain available.
Password changes use a masked prompt; do not paste passwords into commands.
Browser, Remote Desktop and SSH command-console access are not supported.
Closing the console leaves Apache, MySQL and the background tamer task running.
Read docs\WORLD_SERVER_CONSOLE.md and WORLD_SERVER_COMMANDS.txt.
